# Screen_Capture – Downloads

Dieses Repository enthält ausschließlich die **Downloads und Versionshinweise** von Screen_Capture (Windows, x64). Es enthält keinen Quellcode.

## Installation

1. Unter [Releases](../../releases/latest) die Datei `Screen_Capture-Setup-<Version>-x64.exe` herunterladen und ausführen, oder `Screen_Capture-<Version>-x64-portable.zip` entpacken und `Screen_Capture.exe` starten.
2. Optional die Prüfsumme mit `SHA256SUMS.txt` vergleichen: `Get-FileHash <Datei> -Algorithm SHA256`.

Die ausführliche Installationsanleitung (Installation, Portable-Betrieb, Updates) liegt in der Projektdokumentation unter `docs/user/` des Projekts Screen_Capture.

## Updates

Die Update-Prüfung im Programm liest das jeweils neueste veröffentlichte Release dieses Repositories.
